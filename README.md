# bus-guide

## 乗換案内のデータソース

乗換案内は通常 `data/schedules.csv` の時刻表を使います。Transit APIを使いたい場合は、乗換案内ページの「Transit APIを使用する」にチェックして検索してください。APIが候補を返さない場合はCSVの時刻表に切り替わります。曜日ダイヤを手動選択した検索は、Transit APIを有効にしていても選択したCSVダイヤを使用します。

自宅・清瀬駅間では清61系統、自宅・新座駅間では清63・清64系統を、枝番も含めて候補と系統別カードに表示しません。CSVとTransit APIの両方に適用します。

## 西武バス時刻表のOCR

Python 3.12、Tesseract OCR本体と英語学習データ（`eng`）を別途インストールし、`tesseract` コマンドをPATHに追加してください。WindowsではPowerShellで次を実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-timetable.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe fetch_timetable.py
.\.venv\Scripts\python.exe ocr_to_csv.py
```

取得に失敗した場合は修正して取得からやり直してください。`routes.json` は1系統・1停留所・1方向につき1件で、同じURLを複数系統に使用できます。URL一覧の重複は除外済みです。対象ページで系統を一つずつ選択し、時刻表全体を `screenshots` に保存します。OCRは表の罫線と青い分の数字を読み取り、サイトの3列を平日・土曜・休日に変換します。24時台に便がある場合は日付の扱いを決める必要があるためエラーにします。

出力は `timetable.csv` で、既存の `data/schedules.csv` は変更しません。元のCSVは `data/schedules_20261115.csv` にも保存済みです。既存の `timetable.csv` があれば更新前に日付・時刻付きのコピーを作成します。取得やOCRに失敗した系統がある場合、エラーを表示して残りも処理し、CSVは更新しません。OCRには誤認識や読み落としの可能性があるため、利用前に元画像とCSVを必ず照合してください。既存アプリに反映する場合は確認後に `data/schedules.csv` を手動で更新してください。

### 要確認の系統・記号

系統の選択機能を使うため、記号の変換を推測せずに系統を割り当てます。記号の意味と希望する扱いについては後日確認してください。

| 対象 | 記号 | 確認事項 |
|---|---|---|
| 清瀬駅北口・清63系 | 無印、□、大、★ | 提示例の清63、清63-1、清63-2、深夜との対応 |
| 清瀬駅北口・清62系 | 無印、台 | 清62・清62-1との対応 |
| 清瀬駅北口・清61系 | 無印、中、新、営 | 清61・清61-1・清61-2・清61-3との対応 |
| 台田・清62系 | 無印、始 | 始発表示と系統との対応 |
| 下清戸・清61系 | 無印、新、営 | 清61・清61-1・清61-3との対応 |
| 新座駅南口 | 無印、旭、営 | 各系統との対応。無印にも複数系統があります |

新座駅南口の志33・新座02は、ページの行先から `新座営業所方向` と仮設定しています。必要に応じて `routes.json` を修正してください。また、1つのページが複数系統を含むため、系統の追加・廃止時は設定を見直してください。
